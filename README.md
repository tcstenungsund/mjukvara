# Mjukvara — FOSS-rekommendationer för gymnasiet

Här hittar vi kollegor varandras rekommendationer av fri och öppen mjukvara.
Syftet är enkelhet: en elev frågar, vi tittar, vi svarar. Inget googlande,
inget "vad hade du tänkt dig?", inget minnesförlust.

## Tillgång

**[tcstenungsund.github.io/mjukvara](https://tcstenungsund.github.io/mjukvara/)**

## Bidra

1. Skapa en branch (`feature/ny-kategori` eller `fix/uppdatera-video`)
2. Redigera markdown under `docs/`
3. Skicka Pull Request
4. Vänta på review 

## Regler

- **Tabeller per kategori** — samma kolumner, samma ordning
- **Kort och kärnfullt** — eleven ska förstå inom 10 sekunder
- **Källkoll** — dubbelkolla licens och plattform innan commit
- **Ingen proprietary först** — FOSS primärt, proprietärt bara som jämförelse
